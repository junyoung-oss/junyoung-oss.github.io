# Noel Jun Project
## Design Guide

---

# 1. Design Concept

## Core Keyword

- Clean
- Minimal
- Growth
- Experience
- Trust
- Documentation
- Improvement


## Design Philosophy

Noel Jun 사이트는 화려함보다 "신뢰감"과 "성장하는 사람"이라는 이미지를 전달한다.

방문자가 사이트를 보고 다음과 같은 느낌을 받을 수 있도록 한다.

> "이 사람은 꾸준히 배우고 성장하는 사람이구나."
>
> "맡은 일을 책임감 있게 수행하는 사람이구나."
>
> "문제를 발견하고 개선하는 것을 좋아하는 사람이구나."


---

# 2. Visual Identity

## Brand Name

Noel Jun


## Main Message

"인생을 발판 삼아 성장하는 사람"

또는

"사용자 경험을 고민하고, 더 나은 방향을 만들어가는 사람"


## Brand Personality

- 차분함
- 성실함
- 기술적인 느낌
- 따뜻함
- 신뢰감


---

# 3. Layout Concept


## Overall Structure

기본 구조는 개인 홈페이지 + 개발 블로그 + 포트폴리오 형태를 결합한다.


Reference:

- 개발하는 정대리 스타일
- 개인 개발자 블로그
- Notion Portfolio


하지만 단순한 블로그 형태가 아닌,

"한 사람의 성장 과정과 가치관을 보여주는 공간"

으로 구성한다.

# 8. Animation


Animation은 과하지 않게 사용한다.


Purpose:

정보 전달 보조


사용:


## Scroll Animation

Section 등장 효과


Example:

- Fade Up
- Slide


## Hover Effect

Card interaction


Example:

- Project Card
- Skill Card


## Text Animation

Hero 영역에서 사용


Example:


QA Engineer

Problem Solver

Continuous Learner


같은 형태

# 11. Mood Board


사이트가 전달해야 하는 분위기:


좋은 예:

- 개발자 포트폴리오
- 애플 제품 페이지
- Notion 문서
- Linear App


피해야 하는 방향:


- 화려한 기업 홈페이지 느낌
- 과도한 애니메이션
- 게임 홈페이지 같은 분위기


---

# 12. Final Design Goal


Noel Jun 사이트는

"잘 만든 포트폴리오"

보다

"한 사람이 어떻게 성장해왔는지 보여주는 브랜드 공간"

을 목표로 한다.


방문자가 마지막에 느껴야 하는 것:


"이 사람은 계속 배우고,
문제를 해결하며,
함께 일하고 싶은 사람이다."
