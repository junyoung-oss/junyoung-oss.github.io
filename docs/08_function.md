# 1. Functional Goal


## Purpose

Noel Jun 사이트는

"나라는 사람을 소개하고,
경험과 생각을 기록하며,
함께 일할 수 있는 가능성을 만드는 공간"

이다.


기능의 목적은:

- 정보를 쉽게 전달한다.
- 경험을 신뢰성 있게 보여준다.
- 지속적으로 업데이트 가능하게 한다.
